# AI Workbench

A unified workbench for the entire software development lifecycle, powered by AI.

## Project Structure

- `frontend/` - Next.js (React) application
- `backend/` - Spring Boot (Java) REST API
- `docs/` - Requirements and technical documentation
- `design/` - Prototypes and UI/UX assets
- `deploy/` - Infrastructure, Docker, and Kubernetes configs
- `scripts/` - Automation and maintenance scripts

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
./mvnw spring-boot:run
```
